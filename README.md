\-   Customize an existing website using CSS (Ricing).

\-   Improve a previous interactive story using consistent design.

\-   Apply CSS best practices, pseudoclasses, and animations.

\-   Deploy the project locally using NGINX.

Part 2 – Styling My Story



The original HTML branching story was redesigned into a minimalist

narrative game interface inspired by Undertale.



Implemented features:



\-   Consistent layout across all pages

\-   External CSS file

\-   Pseudoclasses (:hover, :focus)

\-   CSS animation using @keyframes

\-   Responsive rules with @media

\-   Styled decision buttons

\-   Images integrated in every scene

\-   Special modifier class for the bad ending

\-   Clean folder structure
