Interactive Story – Undertale Minimal Style

This section contains the redesigned interactive story.

The goal was to transform a simple HTML branching story into a
consistent narrative game interface using only CSS.

------------------------------------------------------------------------

Design Approach

The interface follows a minimalist visual novel structure inspired by
Undertale:

-   Dark background
-   Centered dialogue box
-   Styled decision buttons
-   Hover and focus states
-   Fade-in animation
-   Scene-based organization

------------------------------------------------------------------------

CSS Concepts Applied

-   Class-based selectors
-   Pseudoclasses (:hover, :focus)
-   Keyframe animations (@keyframes)
-   Responsive rules using @media
-   Modifier class for special states (.bad-ending)

------------------------------------------------------------------------

Folder Structure

story/ - inicio/ - decisiones/ - finales/ - css/ - images/

All pages share the same stylesheet to ensure visual consistency.
